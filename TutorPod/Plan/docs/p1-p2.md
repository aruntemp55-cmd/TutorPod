## Env (`apps/api/.env`)

```bash
# Quotas / rate limits
RATE_LIMIT_WINDOW_MS=60000
RATE_LIMIT_MAX_PODS=10
RATE_LIMIT_MAX_QUESTIONS=30
POD_DAILY_QUOTA=20

# Deep links (share)
DEEP_LINK_BASE=https://tutorpod.app

# Optional S3-compatible (AWS / MinIO / R2)
S3_BUCKET=
S3_REGION=us-east-1
S3_ACCESS_KEY_ID=
S3_SECRET_ACCESS_KEY=
S3_ENDPOINT=          # e.g. http://localhost:9000 for MinIO
S3_FORCE_PATH_STYLE=true
```

Copy from `apps/api/.env.example`.

## CI
`npm run ci` — no S3/OpenAI/push keys required.
